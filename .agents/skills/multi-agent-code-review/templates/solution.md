## 制約条件

<!--
  変更を設計するうえで動かせない条件を列挙する。例:
  - 対応プラットフォーム / 最低サポートバージョン
  - パフォーマンス要件(起動時間、レスポンスタイム、メモリ上限)
  - 可用性・データ保全の要件

<!--
  方案の妥当性を判断する根拠になるドキュメントの場所を書く。

  - 仕様書: docs/specs/
