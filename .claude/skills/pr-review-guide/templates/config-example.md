# pr-review-guide プロジェクト設定の例

このファイルを導入先リポジトリの `.claude/pr-review-guide/config.md` にコピーして編集する。
すべてのセクションは任意。不要なセクションは削除してよい。

以下は記入例であり、スキル本体は言語・フレームワークに依存しない。
ここでは Go のバックエンドサービスを例にしている。

## 想定読者

- このリポジトリの Go に不慣れなメンバー(他言語から来た経験者を想定)
- goroutine と channel は既知として扱ってよいが、このリポジトリ独自の抽象は毎回説明する

## 設計文書の所在

- 必読: docs/architecture.md(レイヤー構成と依存の向き)
- 必読: docs/adr/(採用した方式の理由。関連する ADR があれば必ず参照する)
- 参考: docs/specs/

## テスト・ビルドの実行コマンド

- テスト: `make test`
- 単一パッケージ: `go test ./internal/<パッケージ>/...`
- 静的解析: `make lint`

## 毎回触れてほしい観点

- レイヤー間の依存の向き(domain は他レイヤーに依存しない)
- context の伝播とキャンセル時の振る舞い
- エラーのラップ方針(どの層でハンドリングするか)
